# InvoiceFlow

Modern invoice automation dashboard for UMKM and small businesses.

## Features
- Customer management
- Product catalog
- Dynamic invoice generation
- Tax and discount adjustments
- Dashboard summary
- SQLite persistence
- Print-ready invoice preview

## Run locally

```bash
npm install
npm start
```

Then open:

```text
http://localhost:3000
```

## Stack
- Node.js
- Express
- SQLite
- Vanilla HTML/CSS/JS

## Notes
Customer accounts are not required. This app is designed for internal business use, where the business owner or staff creates the invoice for customers.
